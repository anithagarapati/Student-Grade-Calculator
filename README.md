# Student-Grade-Calculator
A Python console application that calculates total marks, percentage , and grade based on marks entered by the user.
# Features
-  calculate total marks of a student
-  calculate percentage of  a student
-  assigns grades (A+,A,B,C,Fail)
-  Accepting marks for multiple subjects
