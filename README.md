# Student-Grade-Calculator
A Python console application that calculates total marks, percentage , and grade based on marks entered by the user.
# Features
-  calculate total marks 
-  calculate percentage 
-  assigns grades based on percentage (A+, A, B, C, Fail)
-  Accepts marks for multiple subjects
-  uses conditional and logical operator (if, and)
